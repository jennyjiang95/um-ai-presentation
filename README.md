# UM × AI — Presentation

Interactive HTML deck and PowerPoint version of the CVS UM × AI showcase.

## Files
- `UM_AI_Presentation.html` — interactive scroll-snap deck (open in browser)
- `UM_AI_Presentation.pptx` — PowerPoint version (15 slides)
- `build_pptx.py` — script that generates the pptx

## View
Open `UM_AI_Presentation.html` directly in any modern browser. Use `↓ / → / Space` to navigate.
