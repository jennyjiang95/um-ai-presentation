02 · Where time goes

A 60-minute review is just four mechanical steps.

Step 01

Open MedCompass

Hot Link entry. CDST opens beside the case in a new viewer.

Step 02

Download docs one-by-one

3–50 attachments per case. Identical names. Manual click each.

Step 03

Scan every page

10–200 pages each. Many faxed PDFs aren't searchable — no copy/paste.

Step 04

Transcribe to QuickBase

Vitals, labs, dates, meds — typed by hand into a 100-field form.

The hardest part isn't the AI.
It's the workflow, the interface, the trust.

The Discipline · Work + Personal

Evaluation is the only way
you know if it's working.

🏥 Work Framework

→
Chunked Scoring
Each field scored separately
→
Metrics
Recall · Precision · Accuracy
🔍Error analysis first. Review 20–50 real outputs manually before building any automated eval.
👑Benevolent indicator. One subject matter expert sets the quality bar — nurses and MDs, not committee vote.
🏥Clinical = false negatives cost more. Missing something is worse than over-flagging.
🏠 Personal Evaluation
The simple test
"Does this actually save me time — or just feel productive?"
Would I pay for it?
If the subscription went away tomorrow, would I miss it? If no — cut it.
Did it unlock something new?
The best tools don't just automate what I did — they let me do things I couldn't before.
Evals tell you if it's working. Keep refining what "good" means.

Lessons Learned · Personal + Work

What the journey
actually taught me.

1
Start with the problem. Always.
Every tool I regret was adopted because it was impressive, not because it solved something real.
2
Evaluation is non-negotiable.
Golden dataset at work. "Does this save time?" personally. Without it you're flying blind.
3
Things move fast. That's the point.
The tools change; the mindset doesn't. OCR pipeline → vision → agentic, in two years.
