// Getting Started

How to use Claude Code

01 / Install
Get it in your terminal
npm i -g @anthropic-ai/claude-code
or download the desktop app from claude.com
02 / Open in project
Run claude in any directory
It automatically reads and maps your entire codebase. No config required.
03 / Give a goal
Plain English. Really.
"Add pagination to the user list" or "Fix the auth bug on line 42" — describe the outcome, not the steps.
04 / Review changes
You stay in control
See exactly which files changed and why. Approve, push back, or redirect. Nothing happens without you.
05 / Iterate
Keep the conversation going
"Now write tests" or "Handle the empty state too." The session continues in context.
💡 Start with a small, well-scoped task to build trust before delegating bigger work
// Getting Started

How to use Hermes Agent

01 / Define task
What runs on autopilot?
"Every Monday, summarize this week's GitHub commits and flag any regressions."
02 / Write the prompt
Craft it once, carefully
Be specific about sources, output format, and what action to take. This is your only investment.
03 / Set schedule
Cron built in natively
Use /schedule command or the built-in cron interface. Daily, weekly, hourly — your call.
04 / Agent runs
You're not needed
Hermes fetches, processes, writes — autonomously. No babysitting. No keeping a terminal open.
05 / Review & refine
Outputs arrive ready
Review results at your leisure. Tune the prompt to improve quality over time — it compounds.
💡 Use Claude Code to build and test the agent logic interactively first, then hand off to Hermes to schedule

// Best Practices

Tips that actually matter

Start small to calibrate trust
Give Claude Code a small, well-scoped task first. See how it thinks. Then escalate scope as trust builds.
Prompt once, run forever
For Hermes: invest time in crafting the first prompt. A great prompt compounds — saves hours every week.
Claude is honest, not compliant
It pushes back on bad plans. Ask "is there a better approach?" before committing — use the friction.
Non-devs: describe outcomes
"I need X to happen when Y" beats any technical spec. Claude figures out the implementation path.
Context is compounding
The more context in your CLAUDE.md or prompt, the better every output. Invest in setup once — it pays every run.
Build → Test → Schedule
Always validate logic interactively in Claude Code before giving Hermes autonomy. Catch errors while you're watching.
