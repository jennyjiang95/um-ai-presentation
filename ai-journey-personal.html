Lesson Learned · Work

AI isn't always the best tool
for every part of the problem.

Gemini was cheaper — but it hallucinated in ways that mattered. Blank pages triggered fabricated content. Document IDs came back wrong or missing.

Issue 1

Blank page fabrication

When a page had no content, Gemini invented information instead of returning empty. In clinical docs, that's dangerous.

Issue 2

Traceability failures

Summaries needed page references. When a reference was missing or mismatched, we fail the AI result — hallucination detected.

Fix Added traditional ML for page duplication detection and page classification before sending to LLM. Pre-processing with classical models → much cleaner LLM input.

EMR Data Advantage
EMR is almost structured data — AI does a much better job on it than on unstructured PDFs. Lesson: structured input = cleaner output.
Evaluation is Simpler
Yes/No decisions → confusion matrix. Recall, precision, accuracy. Clear success criteria meant we could iterate fast. Ground truth is your foundation.
Latency Constraint
Must complete within 30 minutes. Purchased GSU quota to avoid rate limits at peak hours — idle at night, but that's the cost of SLA compliance.
Agent Telephone If information is missing, the agent calls the facility — an automated phone tool that retrieves clinical data before returning a decision. The agent never blocks; it finds another path.
The Discipline · Both Work + Personal

Evaluation is the only way
you know if it's working.

Work

Golden dataset + chunked evaluation

Break the output into components. Align on the template first. Each field is scored independently — find where the model fails, not just whether it failed.

Work

Confusion matrix for decisions

Binary outputs (approve/deny) let you measure recall and precision cleanly. You pick your trade-off: miss a denial, or over-approve? Clinical context drives the threshold.

Lessons Learned · Personal + Work

What the journey
actually taught me.

1
Start with the problem. Always.
Every tool I've regretted was one I adopted because it was impressive, not because it solved something real. Expense tracker, receipt scanner, CDST — all started with friction.
2
Garbage in, garbage out.
Cleaning data before it hits the LLM beats upgrading the model. Adding ML preprocessing to our pipeline beat switching to a "smarter" LLM. Quality input is the real leverage.
3
Evaluation is non-negotiable — at any scale.
Golden dataset at work. "Does this actually save me time?" personally. Without evaluation, you're flying blind and paying for it.
4
AI isn't always the best tool for every step.
Classical ML for page classification, n8n for workflow design, Discord for notification architecture — the best stack is hybrid. Use AI where it wins; don't force it everywhere.
5
Things change very fast. That's actually the point.
OpenClaw → Hermes in months. GPT-3.5 → multimodal vision in a year. The tools change; the mindset (start with a problem) stays constant.
