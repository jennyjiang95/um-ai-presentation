Lessons Learned · Personal + Work

What the journey
actually taught me.

1
Start with the problem. Always.
Every tool I regretted was adopted because it was impressive, not because it solved something real.
2
Garbage in, garbage out.
Cleaning data before the LLM beats upgrading the model. Quality input is the real leverage.
3
Evaluation is non-negotiable.
Golden dataset at work. "Does this save time?" personally. Without it, you're flying blind.
4
AI isn't the best tool for every step.
Classical ML, agents, Discord — the best stack is hybrid. Use AI where it wins.
5
Things change fast. That's the point.
OpenClaw → Hermes in months. The tools change; the mindset (start with a problem) doesn't.
The constant in a fast-changing field

problem.

The technology will keep moving.
