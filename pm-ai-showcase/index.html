Step 01 · Pull the data

I went to BigQuery myself.

The activity-monitor table logs every feedback row from CDST. I wrote one query, ran it from the console, exported the CSV.

-- one query, no ticket, no waiting SELECT * FROM `anbc-hcb-prod.prv_um_cdt_hcb_prod .clinical_decision_activity_monitor_results` WHERE stage = 'feedback' AND caseType = 'cdt inpatient' AND DATE(receiveTimestamp) BETWEEN '2025-01-01' AND '2026-04-30' ORDER BY receiveTimestamp;
Step 02 · Categorize with AI

I had a hypothesis. AI did the heavy lifting. I sanity-checked.

My input

Hypothesis bins

Core summary, discharge, MCG criteria, hallucination, missing info, wrong dates.

AI's job

Bucket every row

Map raw aiFeedbackOption + formField into the categories.

My check

Spot-audit

Pull 30 random rows per bin. Confirm the labels. Adjust the rules.

75% of all 👎 came from one bucket: Core Summary.
